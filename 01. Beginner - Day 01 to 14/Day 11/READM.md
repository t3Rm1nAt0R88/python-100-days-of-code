# Day 11 - Blackjack

## 📖 Overview

Today's project was a console-based implementation of the classic **Blackjack** card game.

The application simulates a game between the player and the computer, dealing cards randomly, calculating scores, handling special card values such as Aces, and determining the winner based on standard Blackjack rules.

- Lists
- Dictionaries
- Loops
- Conditional Statements
- Random Module
- Program Flow
