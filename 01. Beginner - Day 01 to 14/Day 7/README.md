# Day 7 - Hangman

## 📖 Overview

Today's project was a fully functional console implementation of the classic **Hangman** game.

The project combines many concepts learned during the first week, including functions, loops, lists, modules, and game state management.

---

## 📚 Concepts Covered

- Functions
- While Loops
- Lists
- Strings
- Modules
- Random Module

---

## 📂 Files

| File | Description |
|------|-------------|
| `main.py` | Main game logic |
| `hangman_words.py` | Word list |
| `hangman_art.py` | ASCII art used in the game |

---

## 🎯 Key Learnings

- Managing game state
- Organizing code across multiple files
- Building larger Python applications
