# Day 13 - Debugging

## 📖 Overview

Today's focus was on identifying, understanding, and fixing bugs in Python programs.

The exercises involved investigating logical errors, runtime errors, and unexpected program behavior. The day also introduced techniques for systematically examining code and understanding how different parts of a program affect its execution.

---

## 📚 Concepts Covered

- Debugging
- Reading Error Messages
- Logical Errors
- Runtime Errors
- Using Breakpoints
- Code Execution Flow
- Exception Handling
- Modules
- Testing Assumptions

## 🎯 Key Learnings

- Identifying and fixing logical errors
- Using debugging techniques to understand program behavior
