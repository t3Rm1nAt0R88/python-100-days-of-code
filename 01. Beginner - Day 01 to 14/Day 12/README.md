# Day 12 - Number Guessing Game

## 📖 Overview

Today's project was a console-based **Number Guessing Game** where the player attempts to guess a randomly generated number within a limited number of attempts.

The project focused on understanding variable scope, using functions to organize program logic, and implementing different difficulty levels to enhance gameplay.

---

## 📚 Concepts Covered

- Local Scope
- Global Scope
- Constants
- Functions
- Conditional Statements
- Loops
- Random Module

---

## 📂 Files

| File | Description |
|------|-------------|
| `main.py` | Main game logic |
| `logo.py` | ASCII art displayed by the program |

---

## 🎯 Key Learnings

- Understanding the difference between local and global scope
- Using constants to improve code readability
- Organizing code into reusable functions
- Managing game flow based on user input
