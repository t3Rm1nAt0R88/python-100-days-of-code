# Day 8 - Caesar Cipher

## 📖 Overview

Today's project was an implementation of the **Caesar Cipher**, a classic encryption technique that shifts letters in the alphabet to encode or decode messages.

The project reinforced the importance of functions, reusable code, and algorithmic thinking.

---

## 📚 Concepts Covered

- Functions with Parameters
- Return Values
- Loops
- String Manipulation
- Modular Programming
