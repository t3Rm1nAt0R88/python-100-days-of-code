# Day 17 - The Quiz Project

## 📖 Overview

Today's project was a console-based **Quiz Game** built using Object-Oriented Programming principles.

The program presents a series of questions to the user, checks the user's answers, keeps track of the score, and displays the final result at the end of the quiz.

This project provided further practice with classes, objects, attributes, methods, and organizing a Python project across multiple modules.

---

## 📚 Concepts Covered

- Object-Oriented Programming
- Classes
- Objects
- Attributes
- Methods
- Constructors
- Modules
- Lists
- Loops
- Boolean Values
- Conditional Statements

## 📂 Files

| File | Description |
|------|-------------|
| `quiz_project.py` | Main program logic |
| `question_model.py` | Defines the `Question` class |
| `quiz_brain.py` | Handles quiz logic and score tracking |
| `data.py` | Contains the quiz questions and answers |
