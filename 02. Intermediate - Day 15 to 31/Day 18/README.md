# Day 18 - Turtle Graphics

## 📖 Overview

Today's project introduced Python's **Turtle Graphics** module and explored how Python can be used to create visual artwork through programming.

The project focused on using loops, colors, randomization, and turtle movement to create graphical patterns and drawings.

- Randomization
- RGB Colors

- Functions
- Screen and Turtle Configuration
