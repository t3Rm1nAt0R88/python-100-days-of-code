# Day 19 - Turtle Race

## 📖 Overview

Today's project was a **Turtle Race** game built using Python's `turtle` graphics module.

The program creates multiple colored turtles and allows them to race across the screen. The user places a bet on which turtle will win, and the program determines the winner based on the race results.

This project focused on combining graphical programming with loops, functions, randomness, and user input.
