# Day 16 - Coffee Machine (Object-Oriented Programming)

## 📖 Overview

Today's project was a coffee machine program built using **Object-Oriented Programming (OOP)** principles.

The project simulates a coffee machine that can prepare different types of coffee, manage resources, process payments, and provide reports about its current status.

This project marks the beginning of the Object-Oriented Programming section of the course.

---

## 📚 Concepts Covered

- Object-Oriented Programming
- Classes
- Objects
- Attributes
- Methods
- Constructors
- Modules
- Encapsulation
- Importing Classes

---

## 📂 Files

| File               | Description                                             |
| ------------------ | ------------------------------------------------------- |
| `main.py`          | Main program logic                                      |
| `menu.py`          | Contains the `Menu` and `MenuItem` classes              |
| `coffee_maker.py`  | Manages coffee machine resources and coffee preparation |
| `money_machine.py` | Handles payment processing and money management         |

---

## 🎯 Key Learnings

- Understanding the fundamentals of Object-Oriented Programming
- Creating and using classes and objects
- Organizing code into separate modules
- Using methods to define object behavior
- Managing object attributes and state
