# Day 1 - Band Name Generator

## 📖 Overview

Today's focus was on learning the fundamentals of Python programming. I explored how to display output, accept user input, store values in variables, and manipulate strings.

The project for the day was a simple **Band Name Generator**, which creates a band name by combining the user's hometown and pet's name.

- Variable Naming Conventions
