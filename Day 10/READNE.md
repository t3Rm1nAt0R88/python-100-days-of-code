# Day 10 - Calculator

## 📖 Overview

Today's project was a console-based **Calculator** application capable of performing basic arithmetic operations such as addition, subtraction, multiplication, and division.

The project emphasized the use of functions, dictionaries, and program flow to create a reusable calculator that allows users to perform multiple calculations without restarting the application.

---

## 📚 Concepts Covered

- Functions with Return Values
- Dictionaries
- Storing Functions in Dictionaries
- Loops
- Conditional Statements
- Program Flow

---

## 📂 Files

| File | Description |
|------|-------------|
| `main.py` | Main calculator logic |
| `art.py` | ASCII art displayed by the program |

---

## 🎯 Key Learnings

- Returning values from functions
- Using dictionaries to map operations to functions
- Building reusable and modular code
- Managing program flow with loops and user choices
