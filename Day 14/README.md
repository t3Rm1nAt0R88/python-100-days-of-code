# Day 14 - Higher or Lower

## 📖 Overview

Today's project was a console-based **Higher or Lower** game where the player compares two accounts and tries to determine which one has a higher number of followers.

The project combined functions, dictionaries, lists, loops, and random selection to create an interactive game with a scoring system.

---

## 📚 Concepts Covered

- Dictionaries
- Lists
- Functions
- Loops
- Conditional Statements
- Random Module
- Game State Management

---

## 📂 Files

| File           | Description                                            |
| -------------- | ------------------------------------------------------ |
| `main.py`      | Main game logic                                        |
| `game_data.py` | Data containing the accounts and their follower counts |
| `art.py`       | ASCII art displayed by the program                     |

---

## 🎯 Key Learnings

- Working with structured data stored in dictionaries
- Selecting random items from a list
- Managing game state and scores
- Comparing values stored in dictionaries
- Organizing a larger program across multiple Python files
