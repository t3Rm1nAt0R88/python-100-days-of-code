# Day 15 - Coffee Machine

## 📖 Overview

Today's project was a console-based **Coffee Machine** application that allows users to order different drinks, processes payments, and manages available resources such as water, milk, coffee, and money.

The project combined functions, loops, conditional statements, dictionaries, and modular programming to simulate the functionality of a real coffee machine.

---

## 📚 Concepts Covered

- Functions
- Dictionaries
- Loops
- Conditional Statements
- While Loops
- Modular Programming
- Resource Management

---

## 📂 Files

| File               | Description                                                   |
| ------------------ | ------------------------------------------------------------- |
| `main.py`          | Main coffee machine logic                                     |
| `menu.py`          | Contains the available drinks and their ingredients and costs |
| `coffee_maker.py`  | Manages coffee machine resources and drink preparation        |
| `money_machine.py` | Handles payment processing and money management               |

---

## 🎯 Key Learnings

- Organizing a larger program across multiple Python files
- Using classes and modules to separate responsibilities
- Managing resources and user transactions
- Building a program with multiple interacting components
