## 📖 About

This repository documents my progress through **100 Days of Code: The Complete Python Pro Bootcamp** by **Dr. Angela Yu**.

The course encourages daily coding practice through a series of practical projects designed to progressively build Python programming skills.

By the end of this journey, I aim to have completed **100 days of coding**, built numerous Python projects, and developed a strong foundation in Python and software development.

📌 **Course Link:** [100 Days of Code - The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code/)

---

## 🎯 Course Description

The course covers a wide range of Python programming concepts, including:

✅ **Python Fundamentals** - Variables, data types, control flow, functions, and debugging  
✅ **Data Structures** - Lists, dictionaries, tuples, and sets  
✅ **Object-Oriented Programming** - Classes, objects, inheritance, and advanced OOP concepts  
✅ **GUI Development** - Building applications with Tkinter  
✅ **Game Development** - Creating games using Python and Turtle  
✅ **File Handling & Data Processing** - Reading, writing, and working with files  
✅ **Web Development** - HTML, CSS, Flask, and REST APIs  
✅ **Web Scraping & Automation** - Requests, BeautifulSoup, Selenium, and automation  
✅ **Data Science** - Pandas, NumPy, Matplotlib, and data analysis  
✅ **Databases** - SQL, SQLite, PostgreSQL, and database integration  
✅ **APIs & Authentication** - Working with external APIs and authentication systems  
✅ **Version Control** - Git, GitHub, and professional development workflows

The goal is to progress from Python fundamentals to building practical, real-world applications.
