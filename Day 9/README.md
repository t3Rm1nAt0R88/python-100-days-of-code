# Day 9 - Secret Auction

## 📖 Overview

Today's project was a console-based **Secret Auction** application where multiple participants submit their bids anonymously.

The program collects each bidder's name and bid amount, stores the information using a dictionary, and determines the highest bidder once the auction is complete.

---

## 📚 Concepts Covered

- Dictionaries
- Functions
- Loops
- Conditional Statements
- Key-Value Pairs
- Finding Maximum Values
